# Применение искусственного интеллекта в клинической медицине

Научно-исследовательская работа (магистратура, «Прикладная математика и информатика»).
Код к работе: собственная логистическая регрессия на NumPy с L2-регуляризацией для
классификации опухолей по набору Breast Cancer Wisconsin (Diagnostic), 569 объектов, 30 признаков.

## Что делает код

1. Делит данные на development (80%) и независимый тест (20%), стратифицированно.
2. На development повторной стратифицированной кросс-валидацией 5×10 подбирает силу L2-штрафа
   (критерий log-loss, правило одной стандартной ошибки).
3. По out-of-fold вероятностям выбирает порог: максимум специфичности при чувствительности не ниже 0.95.
4. Обучает итоговую модель на всём development и один раз оценивает на тесте
   (доверительные интервалы: Клоппер–Пирсон для долей, стратифицированный бутстреп для остальных метрик).
5. Сравнивает результат с логистической регрессией sklearn и случайным лесом.

Метка класса: 1 = злокачественная опухоль.

## Установка

Нужен Python 3.13 (проверено на нём).

```
python -m venv .venv
.venv\Scripts\activate        # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Первые четыре шага зависят друг от друга через папку `results/` (`compare_models.py` требует результатов `main.py`), проверку разделимости можно запускать отдельно.

```
python main.py                 # основная схема: подбор штрафа и порога, оценка на тесте
python compare_models.py       # сравнение с sklearn и случайным лесом
python make_figures.py         # рисунки в results/figures/
python make_report.py          # итоговая таблица results/l2_report.xlsx
python check_separability.py   # проверка линейной разделимости классов
```

Дополнительные флаги `main.py`:

- `--quick`: повторная CV 5×2 вместо 5×10, результаты в `results/quick/` (только для проверки);
- `--skip-test`: не обращаться к тестовой выборке.

Полный прогон `main.py` занимает заметное время (550 обучений на каждое значение штрафа).

## Структура

```
main.py                  основной сценарий
compare_models.py        сравнение моделей
make_figures.py          рисунки
make_report.py           сборка xlsx-отчёта
check_separability.py    проверка разделимости классов
src/
  models.py              собственная логистическая регрессия (сигмоида, потеря, градиенты, обучение)
  experiments.py         сетка штрафа, кросс-валидация, правило одной SE, выбор порога
  evaluation.py          метрики и доверительные интервалы
  data_loader.py         загрузка данных
  preprocessing.py       разбиение на development и тест
  visualisation.py       функции построения рисунков
  report.py              сборка отчёта
tests/                   тесты (pytest)
results/                 результаты прогонов: CSV, JSON и рисунки
```

Фиксированное зерно: `random_state=42`, повторный запуск даёт те же числа.
